# 🌦️ Weather App

A simple and responsive **Weather App** built using **HTML, CSS, and JavaScript**.

The application allows users to search for a city and view its current weather information.

## 🌐 Live Demo

👉 [Visit Weather App](https://aryanh12345.github.io/Weather-App/)

## 🚀 Features

- 🌍 Search weather by city
- 🌡️ Display temperature
- ☁️ Display current weather condition
- 🔍 Easy-to-use search interface
- 📱 Responsive design
- 🎨 Clean and simple UI
- ⚡ Fast and lightweight
- 🌐 Fetches weather data using an API

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Application logic and API integration
- **Weather API** – Weather data
